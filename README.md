## The word

**mnemonic**

The word for remembering things is itself the hardest word in English
to remember how to spell — it starts with a silent *m*. Erase
"mnemonic" and the language loses the word for memory tricks, while the
one word nobody could spell anyway is the one nobody will miss trying
to spell. The joke is the word itself: a memory aid you cannot remember.

## How it works

`main.py` (Python 3.13, stdlib only, no network) writes exactly the word
`mnemonic` — 8 characters, no trailing newline — to
`/output/entry.txt`, then self-checks the file against the gate (UTF-8,
1–77 characters, not whitespace-only, a single word). Deterministic:
every run writes byte-identical output.
